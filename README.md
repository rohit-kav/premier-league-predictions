⚽ Premier League Match Predictor

A machine learning project that predicts match outcomes in the English Premier League using historical match data and statistical features.

📌 Overview

The English Premier League is one of the most competitive and widely followed soccer leagues in the world. This project explores whether machine learning can predict match outcomes (win, loss/draw) based on historical match statistics.
The goal is to build a model that gives users an edge in predicting match results—whether for analytics, betting insights, or general curiosity.

🛠️ Tech Stack
Python
Pandas, NumPy - Data Cleanup 
Matplotlib, Seaborn - EDA & Visualization
Scikit-learn - ML Models
Beautiful Soup - Web Scraping (FBRef data source)

📊 Dataset
Seasons used:
2020–21
2021–22
2022–23 (partial)
Total matches per season: 380
Data source: FBRef (scraped manually)
